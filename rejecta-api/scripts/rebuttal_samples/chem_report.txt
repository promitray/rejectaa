Reviewer 1:
1. I would desk reject this for insufficient novelty. Thermally triggered release from Diels-Alder adducts and nitroxide-based fluorescence quenching are both well known, and the combination is not clearly differentiated from existing work. This manuscript would be better suited to a specialized polymer journal.
2. The synthesis procedures are described without sufficient detail on the characterization of the final products, which raises concerns about reproducibility. SEC and DLS data for P2 and P3 should be reported.

Reviewer 2:
1. The authors claim that the system is an efficient self-reporting release system, but there is no comparison with existing photo- or thermo-responsive release systems.
2. It is unclear why the cycloreversion was run at 90 C for 50 h and whether the polymer backbone is stable under these conditions.
